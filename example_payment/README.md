# JPG payment and invoice image examples

Use this folder for ten sample JPG payment or invoice images, ordered by visual clarity:

| Level | Suggested filename | Image quality |
| ---: | --- | --- |
| 1 | `level-01.jpg` | Clearest, easiest to read |
| 2 | `level-02.jpg` | Very clear |
| 3 | `level-03.jpg` | Clear |
| 4 | `level-04.jpg` | Mostly clear |
| 5 | `level-05.jpg` | Moderate quality |
| 6 | `level-06.jpg` | Some details difficult to read |
| 7 | `level-07.jpg` | Blurry or poorly lit |
| 8 | `level-08.jpg` | Several fields hard to read |
| 9 | `level-09.jpg` | Very unclear |
| 10 | `level-10.jpg` | Least clear; important fields may be unreadable |

Test an image manually in Liggy by opening **E-Invoice**, selecting the JPG, and choosing **Analyze Invoice**. Compare the extracted values with the image and record which fields needed correction. Review the agent's verification result before approving an invoice. These images are not automatically processed by the scripts in `tests/`.

Use synthetic or anonymized samples only. Do not commit real customer or payment details.
